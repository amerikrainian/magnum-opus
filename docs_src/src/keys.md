# Keys

**F1** lists the keys that do something right where you are; Enter on a row runs that key.

| Key | What it does |
|---|---|
| Up and Down Arrow | Move through a list |
| Left and Right Arrow | Move across a row; change a slider's value |
| Tab and Shift+Tab | Next and previous group of controls |
| Enter | Activate; open a dropdown's list |
| Escape | Back: close a list, a dialog or a screen (the game's own Escape) |
| Home and End | First and last item |
| Alt+Up and Alt+Down | Previous and next section |
| Letters | Jump to the item starting with what you type |
| F1 | Keys that work here |
| Ctrl+Shift+M | The Magnum Opus menu (settings, all keys) |
| Ctrl+Shift+A | Hand the keyboard back to the game, and take it again |

## Dropdowns

Language, Resolution and Keyboard Layout in Options are dropdowns: they read as "combo box" with
their current value. Enter opens the list on the current value; Up and Down move, Enter picks,
Escape closes the list without changing anything.

## The game's own keys

Keys the mod does not use reach the game unchanged. A few of the game's keys stay available on
top of the mod's: on a puzzle's info screen, Delete asks to delete the selected solution and F2
renames it; in a cutscene, Space and Tab advance.
