# Key Reference

Every key here can be rebound: mod menu (Ctrl+Shift+M), All keys.

## Everywhere

| Key | Action |
| --- | --- |
| Tab / Shift+Tab | Next / previous stop |
| Arrows | Move within the stop |
| Home / End | First / last item of the stop |
| Alt+Up / Alt+Down | Previous / next section |
| Enter | Activate |
| Escape | Back, cancel or close |
| Letters | In a list, jump to the item starting with them |
| F1 | Keys that work here |
| Ctrl+Shift+M | Mod menu |
| Ctrl+Shift+N | Keyboard navigation on / off |

## Board: moving and reading

| Key | Action |
| --- | --- |
| Q / E / A / D / Z / C | Cursor northwest / northeast / west / east / southwest / southeast |
| Numpad 7 / 9 / 4 / 6 / 1 / 3 | The same |
| Alt+Shift with a hex key, Alt with a numpad key | Skip to the next hex that reads differently |
| Ctrl+Home | Cursor to 0, 0 (on a production puzzle without that hex, the first chamber's centre) |
| Page Up / Page Down | Production puzzles: previous / next chamber |
| [ / ] | Previous / next category |
| , / . | Previous / next item of the category |
| Backslash | Items move the cursor (the default) or stay and say where they are |
| Slash | Cursor to the last item spoken |
| M | Mark the hex with the next free number |
| Shift+M | Clear the mark here |
| Alt+Shift+M | Clear every mark |
| Ctrl+1 to Ctrl+9 | Jump to that mark |
| S | Details of the hex |
| W | The molecule on the hex |
| X | The six neighbours |
| Ctrl+Up / Ctrl+Down | Choose which part on the hex the building keys act on |

## Board: building

| Key | Action |
| --- | --- |
| Enter | Pick up / put down the part under the cursor |
| Ctrl+Enter | Pick up a copy |
| Escape | While carrying: put it back where it was. Otherwise: clear the selection |
| Shift+A / Shift+D | Rotate counter-clockwise / clockwise round the cursor hex |
| Shift+W / Shift+S | Longer / shorter arm |
| Delete | Remove the part, or the selection |
| Shift+Enter | Extend the track from its end; hex keys lay or take back track, Enter finishes |
| Shift+Space | Mark a corner; again on the opposite corner selects every part in the rectangle |
| Ctrl+Shift+Space | Add or remove the part under the cursor from the selection |
| Ctrl+A | Select every part |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy, cut, paste parts |

## Program

These work on the Program stop, and on the board.

| Key | Action |
| --- | --- |
| Up / Down | Previous / next arm |
| Left / Right | Previous / next cycle |
| Home / End | The arm's first / last instruction |
| 1 to 9 | Jump to that arm |
| Enter | Program stop: run to this cycle |
| Shift+arrows | Select a rectangle of cells |
| Ctrl+Shift+A | Select every instruction |
| Ctrl+Shift+Left / Ctrl+Shift+Right | Move the arm's program, or the selection, a cycle left / right |
| Delete | Clear the cell, or the selection |
| Backspace | Clear the cell before |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy, cut, paste instructions |
| Escape | Clear the selection |
| Alt+Backspace | Jump between the board and the program |

## Instructions

| Key (QWERTY) | Instruction |
| --- | --- |
| A / D | Rotate counter-clockwise / clockwise |
| Q / E | Pivot counter-clockwise / clockwise |
| W / S | Extend / retract |
| F / R | Grab / drop |
| G / T | Move plus / minus along a track |
| C | Reset |
| V | Repeat |
| X | Period override |
| B | Halt |

## Running and more

| Key | Action |
| --- | --- |
| Space | Play / pause |
| Ctrl+Space | Step one cycle |
| Alt+Space | Fast forward |
| Ctrl+Shift+S | Score |
| Alt+P | Each product's count |
| Ctrl+Shift+T | The puzzle's notes |
| Ctrl+Shift+D | The game's diagram of the elements |
| Ctrl+T | Repeat the tutorial step |
| Ctrl+Z | Undo |
| Ctrl+Y / Ctrl+Shift+Z | Redo |

## Parts and molecules

| Key | Action |
| --- | --- |
| Enter | Parts stop: pick up a new part at the board cursor |
| S | Parts stop: the part's description |
| W | Parts stop: open the reagent's or product's molecule |
| Hex keys | Molecule: walk its atoms |
| Shift+A / Shift+D | Molecule: turn it round the cursor hex (a turned copy, for looking only) |
| X | Molecule: the neighbours |

## Sigmar's Garden

| Key | Action |

| , / . | Previous / next free marble |
| X | The neighbours |
| Space | Advance the story |

## Molecule editor

| Key | Action |
| --- | --- |
| Hex keys | Move over the grid |
| Enter | Place the selected atom |
| Delete | Remove the atom |
| Shift+Q / E / A / D / Z / C | Bond toward that neighbour with the selected bond type; again removes it |
| [ / ] | Previous / next atom |
| Shift+[ / Shift+] | Previous / next bond type |
| W | The molecule |
| X | The neighbours |
| Ctrl+S | Save |
