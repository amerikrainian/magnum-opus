# Changelog

## V0.0.3

- When a story is done, we no longer narrate any visible lines. You can, however, still reach them in the tab stops.
- Playing a solution no longer interrupts speech. A toggle exists for the old behavior.
- We now allow you to shorten compass directions anywhere they are shown.
- You can now toggle snapping with \, in which case the cycling keys will report distance to your cursor. / will jump to the item in the given category.
