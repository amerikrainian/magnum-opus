# Changelog

## V0.1.0

- First release. Magnum Opus loads into the stock Opus Magnum (community-edition branch) and speaks through your screen reader.
- Readable and operable: the title screen (any key continues), the campaign map (items, chapters, journal, campaign switch, options), letters, cutscenes, puzzle info (solutions, New, Open, Rename, Copy, Delete), message boxes, the pause menu, Options (real dropdowns for Language, Resolution and Keyboard Layout) and Controls.
- F1 lists the keys that work where you are; Ctrl+Shift+M opens the mod menu; Ctrl+Shift+A hands the keyboard back to the game and takes it again.
- When the game updates before the mod does, the mod keeps working on automatically matched names, downloads the community's names for the new build in the background, and tells you each step.
